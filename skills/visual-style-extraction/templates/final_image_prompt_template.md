# Final Image Prompt Template

Write the final prompt in English.

For 4:1 banners, use `production_templates/banner_4_1_production.yaml` first. Treat this file as the generic fallback for non-banner prompts or quick manual prompts.

Recommended structure:

```text
Create a [format/use case] for [theme/campaign].

Visual style:
[style type, design language, mood]

Composition:
[layout skeleton, hierarchy, focal point, rhythm, whitespace]

Key visual system:
[symbolized objects, typography relationship, color blocks, props, graphic elements]

Typography:
[role of text, scale relationship, placement, contrast]

Color and material:
[palette, material, texture, light, background]

Design quality constraints:
[restraint, what must be avoided, anti-AI rules]

Output requirements:
[aspect ratio, clean composition, no random clutter, no unintended brand marks or logo text]
```
