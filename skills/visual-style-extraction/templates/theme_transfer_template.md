# Theme Transfer Template

Before writing the final prompt, run this calibration.

```yaml
pre_generation_calibration:
  original_design_sense:
    -
  must_keep_relationships:
    -
  new_theme_translation:
    -
  hierarchy_plan:
    -
  restraint_rules:
    -
  anti_ai_risks:
    -
```

Then write:

```yaml
design_transfer_principle:
  preserve:
    -
  symbolize_new_theme_by:
    -
  must_not_happen:
    -
  theme_objects_to_abstract:
    -
  elements_allowed_to_change:
    -
  elements_that_must_remain_structural:
    -
```

Rules:

- Do not only replace objects.
- Preserve design judgment, hierarchy, layout skeleton, rhythm, and restraint.
- New theme elements must be symbolized, graphically abstracted, or integrated into the original composition system.
- Avoid turning the style into a generic illustration scene.
