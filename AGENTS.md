# Visual Style Workflow

## Project Role

You are working on a visual style extraction and AI image prompt workflow for operation design, campaign KV, lifestyle posters, and platform marketing visuals.

Your task is not only to describe visual elements. Extract reusable design systems.

## Core Principle

Always prioritize design judgment over element listing.

A visual style extraction must answer:

- Why does this design work?
- What is the core design decision?
- What hierarchy is being controlled?
- What layout skeleton supports the image?
- What is restrained?
- How is the theme translated into form?
- What should not be added because it would damage the design sense?

## Default Workflow

For every visual style extraction, follow this order:

1. Style Essence Check
   - Determine whether the reference is flat graphic design, 2.5D sticker-like props, realistic photography, clay-like 3D, commercial 3D rendering, collage, illustration, or typography-led design.
   - Do not misclassify flat high-saturation marketing graphics as 3D just because some objects have partial depth.
   - Do not misclassify 3D character-led campaign KV as a flat graphic poster.

2. Style Positioning
   - Identify style type, usage scene, platform context, and closest design language.

3. Core Visual Logic
   - Explain what visual relationship makes the image work.

4. Design Quality Logic
   - Analyze where the design sense comes from.
   - Identify key design decisions.
   - Explain hierarchy control.
   - Explain layout intention.
   - Identify restraint.
   - Explain theme-form translation.
   - State what would damage the design sense.

5. Composition System
6. Element System
7. Typography System
8. Color System
9. Texture and Material
10. Information Density
11. Mood
12. Anti-AI Rules
13. Style Library YAML
14. Final Image Prompt

## Theme Transfer Rule

When changing a theme, do not only replace objects.

Always transfer the original design relationship first:

- typography relationship
- hierarchy
- layout skeleton
- rhythm
- restraint
- symbolic translation method
- visual metaphor

New theme elements must obey the original design system.

## Output Language

Default output language: Chinese.

Prompt language: English.
