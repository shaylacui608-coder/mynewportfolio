# Reference Contact Sheets

This folder contains the contact-sheet images used during the original style reading and clustering process.

It does not contain every raw reference image. Instead, it keeps the lightweight overview images that were used to inspect multiple references at once.

## Folder Guide

- `00_overview`: full-batch overview contact sheets and extra round-two overview sheets.
- `01_by_original_folder`: contact sheets grouped by the original desktop folder names.
- `02_by_poster_style`: contact sheets grouped by poster style after visual clustering.
- `03_by_poster_style_round2`: updated poster-style grouping after the second clustering pass.
- `04_by_ontology`: higher-level visual ontology grouping used during style analysis.
